# F407ZGT6_V3
本仓库是基于浩普STM32F407ZGT6_V3开发板的系列工程

## 目录结构

| 目录 | 说明 |
|---|---|
| `APP/` | 应用任务 |
| `BSP/` | 板级驱动 |
| `SVC/` | 服务层 |
| `Core/` | CubeMX 生成代码 |
| `Drivers/` | STM32 HAL 库与 CMSIS |
| `FATFS/` | FatFS 文件系统 |
| `Middlewares/` | FreeRTOS、LVGL |
| 根目录 | 工程配置 |

## 说明

后续不同的项目会在不同的模板工程上创建分支并制作提交
